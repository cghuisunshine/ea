ANDY'S VISUAL SUPPORT — LOCAL FILES

How to run the interactive activity

1. Unzip the downloaded package.
2. Keep all four files together in the same folder.
3. Double-click "andy-interactive-visual-support.html".
4. The activity will open in your web browser and does not need internet access.

Included files

- andy-interactive-visual-support.html — interactive activity for Andy
- andy-visual-support-presentation.html — presentation script
- andy-visual-support-board.png — visual artwork used by the activity
- README.txt — these instructions

Audio note

The "Speak my message" feature uses the speech voice built into the web browser or device. If no sound plays, check the device volume and allow audio playback in the browser.

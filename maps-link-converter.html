Google ↔ Apple 导航链接转换

粘贴 Google Maps 或 Apple Maps 的导航链接，或直接粘贴 Google Maps 的分享文字。页面会识别地点并生成另一家的导航链接。无需 API Key。

Google 的 maps.app.goo.gl 短链接本身不包含可直接读取的地点信息，而且静态 GitHub Pages 不能跨域读取它最终跳转到哪里。但如果你从 Google Maps 点“分享”后，把地点名称 + 短链接整段文字一起粘贴，本页会用地点名称直接生成 Apple Maps 导航链接。
